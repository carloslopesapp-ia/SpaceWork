# SpaceWork — Plano 1: Fundação (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ter o projeto Cloudflare a funcionar de ponta a ponta com base de dados, autenticação completa (registo, login, logout, sessão, alterar senha), utilizador master e uma interface mínima (login, registo, layout autenticado e conta).

**Architecture:** Um único Worker (Hono, TypeScript) serve a API em `/api/*` e a SPA React (build do Vite) como assets estáticos. A D1 guarda utilizadores, sessões e as restantes tabelas da especificação (já criadas aqui, usadas nos planos seguintes). Os testes de API correm no runtime real do Workers com D1 e R2 locais. A senha é guardada com PBKDF2-SHA256; a sessão vai num cookie `HttpOnly` e a D1 guarda só o hash do token.

**Tech Stack:** TypeScript 7, Hono 4, React 19, React Router 8, TanStack Query 5, Tailwind CSS 4, Vite 8 com `@cloudflare/vite-plugin`, Wrangler 4, Vitest 4.1 com `@cloudflare/vitest-plugin`.

**Spec:** [docs/superpowers/specs/2026-10-03-spacework-design.md](../specs/2026-10-03-spacework-design.md) (secções 2, 3, 4 e a parte de autenticação das secções 6 e 8). Índice dos planos: [README.md](README.md).

## Global Constraints

Valores copiados da especificação; todas as tarefas os cumprem implicitamente.

- TypeScript em todo o código. Backend: Hono. Frontend: React, React Router, TanStack Query, Tailwind CSS, Vite (com `@cloudflare/vite-plugin`). Testes: Vitest com `@cloudflare/vitest-plugin`. **Vitest tem de ser `^4.1`** (o Vitest 5 não é compatível com o plugin).
- IDs: `crypto.randomUUID()` (texto). Datas: inteiros (milissegundos Unix).
- Email normalizado (trim + minúsculas, máx. 254 caracteres). Senha de 8 a 128 caracteres.
- Senhas: PBKDF2-SHA256 via WebCrypto, salt aleatório de 16 bytes, 100 000 iterações, formato `pbkdf2-sha256$<iterações>$<salt_b64>$<hash_b64>`.
- Sessão: token de 32 bytes aleatórios em cookie `sw_session`: `HttpOnly; SameSite=Lax; Path=/; Max-Age=<SESSION_TTL>` (14 dias), com `Secure` quando o pedido é HTTPS. A D1 guarda só o SHA-256 do token.
- Pedidos POST/PUT/PATCH/DELETE: o cabeçalho `Origin` tem de existir e coincidir com a origem do pedido, caso contrário 403.
- Registo: cria sempre `role = user`, `status = active`, `quota_bytes = DEFAULT_QUOTA_BYTES` (1073741824) e inicia sessão; email existente devolve 409.
- Login: erro sempre genérico "Email ou senha inválidos."; verificação de hash "falsa" quando o email não existe; 5 ou mais falhas do mesmo email nos últimos 15 minutos devolvem 429; conta suspensa só revela 403 depois de a senha estar certa; contas `deleting` tratam-se como inexistentes.
- Erros da API em JSON: `{ "error": "<código>", "message": "<texto>" }`.
- Cabeçalhos em todas as respostas do Worker: `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Referrer-Policy: same-origin`. Os assets estáticos usam `public/_headers` com os mesmos valores.
- Interface em português europeu e responsiva.
- A senha e o email do master **nunca** são escritos no código, na configuração ou no repositório (o seed lê-os de variáveis de ambiente).
- **Nenhum `git push` sem confirmação explícita do utilizador.**

```ts
      "login_failures",
      "sessions",
      "shares",
      "users",
```

### Task 3: Criptografia e validação

**Files:**
- Create: `src/worker/lib/crypto.ts`, `src/worker/lib/validation.ts`
- Test: `test/crypto.test.ts`, `test/validation.test.ts`

**Interfaces:**
- Produces (`src/worker/lib/crypto.ts`):
  - `PBKDF2_ITERATIONS: 100000`
  - `hashPassword(password: string, iterations?: number): Promise<string>` → `pbkdf2-sha256$<iter>$<salt_b64>$<hash_b64>`
  - `verifyPassword(password: string, stored: string): Promise<boolean>` (hash malformado → `false`, nunca lança)
  - `randomToken(byteLength?: number): string` (base64url, 32 bytes por defeito → 43 caracteres)
  - `sha256Hex(input: string): Promise<string>`
- Produces (`src/worker/lib/validation.ts`): `PASSWORD_MIN_LENGTH = 8`, `PASSWORD_MAX_LENGTH = 128`, `normalizeEmail(raw: string): string`, `isValidEmail(email: string): boolean` (espera email já normalizado), `isValidPassword(password: string): boolean`.
- `crypto.ts` só usa WebCrypto, `btoa`/`atob` e `TextEncoder`, e nenhuma sintaxe TypeScript que exija transformação: o `scripts/seed-master.ts` (Task 8) importa-o diretamente em Node.

- [ ] **Step 1: Escrever os testes que falham**

`test/crypto.test.ts`:

```ts
import { describe, expect, it } from "vitest";
import {
  hashPassword,
  PBKDF2_ITERATIONS,
  randomToken,
  sha256Hex,
  verifyPassword,
} from "../src/worker/lib/crypto";

describe("hashPassword / verifyPassword", () => {
  it("gera o formato pbkdf2-sha256$<iterações>$<salt>$<hash>", async () => {
    const hash = await hashPassword("senha-segura-123");
    const parts = hash.split("$");
    expect(parts).toHaveLength(4);
    expect(parts[0]).toBe("pbkdf2-sha256");
    expect(parts[1]).toBe(String(PBKDF2_ITERATIONS));
    expect(PBKDF2_ITERATIONS).toBe(100_000);
    expect(atob(parts[2])).toHaveLength(16);
    expect(atob(parts[3])).toHaveLength(32);
  });

  it("aceita a senha certa e rejeita a errada", async () => {
    const hash = await hashPassword("senha-segura-123");
    expect(await verifyPassword("senha-segura-123", hash)).toBe(true);
    expect(await verifyPassword("senha-segura-124", hash)).toBe(false);
    expect(await verifyPassword("", hash)).toBe(false);
  });

  it("usa um salt diferente de cada vez", async () => {
    const a = await hashPassword("mesma-senha");
```

```ts
// Só usa WebCrypto, btoa/atob e TextEncoder, disponíveis no Workers e no Node:
// o script scripts/seed-master.ts importa este ficheiro para gerar hashes no mesmo formato.
// Não usar sintaxe TypeScript que exija transformação (enums, parameter properties).

const SCHEME = "pbkdf2-sha256";
const SALT_BYTES = 16;
const HASH_BYTES = 32;

/** Máximo aceite pelo WebCrypto do Workers em produção. O valor usado fica guardado no hash. */
export const PBKDF2_ITERATIONS = 100_000;

function toBase64(bytes: Uint8Array): string {
  let binary = "";
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return btoa(binary);
}

function fromBase64(value: string): Uint8Array<ArrayBuffer> {
  const binary = atob(value);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes;
}

function toHex(bytes: Uint8Array): string {
  return Array.from(bytes, (byte) => byte.toString(16).padStart(2, "0")).join("");
}

function constantTimeEqual(a: Uint8Array, b: Uint8Array): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a[i] ^ b[i];
  return diff === 0;
}

async function derive(
  password: string,
  salt: Uint8Array<ArrayBuffer>,
  iterations: number,
): Promise<Uint8Array> {
  const key = await crypto.subtle.importKey(
    "raw",
    new TextEncoder().encode(password),
    "PBKDF2",
    false,
    ["deriveBits"],
  );
  const bits = await crypto.subtle.deriveBits(
    { name: "PBKDF2", hash: "SHA-256", salt, iterations },
    key,
    HASH_BYTES * 8,
  );
  return new Uint8Array(bits);
}

/** Devolve `pbkdf2-sha256$<iterações>$<salt_b64>$<hash_b64>`. */
export async function hashPassword(
  password: string,
  iterations: number = PBKDF2_ITERATIONS,
): Promise<string> {
  const salt = crypto.getRandomValues(new Uint8Array(SALT_BYTES));
  const hash = await derive(password, salt, iterations);
  return `${SCHEME}$${iterations}$${toBase64(salt)}$${toBase64(hash)}`;
}

/** Verifica a senha contra um hash guardado. Qualquer hash malformado devolve false. */
export async function verifyPassword(password: string, stored: string): Promise<boolean> {
  const parts = stored.split("$");
  if (parts.length !== 4 || parts[0] !== SCHEME) return false;
  const iterations = Number.parseInt(parts[1], 10);
  if (!Number.isInteger(iterations) || iterations < 1) return false;
  let salt: Uint8Array<ArrayBuffer>;
  let expected: Uint8Array<ArrayBuffer>;
  try {
    salt = fromBase64(parts[2]);
    expected = fromBase64(parts[3]);
  } catch {
    return false;
  }
  if (expected.length !== HASH_BYTES) return false;
  const actual = await derive(password, salt, iterations);
  return constantTimeEqual(actual, expected);
}

/** Token aleatório em base64url (sem `=`), com `byteLength` bytes de entropia. */
export function randomToken(byteLength = 32): string {
  const bytes = crypto.getRandomValues(new Uint8Array(byteLength));
  return toBase64(bytes).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

export async function sha256Hex(input: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(input));
  return toHex(new Uint8Array(digest));
}
```

```ts
  await env.DB.batch(TABLES.map((table) => env.DB.prepare(`DELETE FROM ${table}`)));
}

interface ApiInit {
  method?: string;
  json?: unknown;
  body?: BodyInit;
  cookie?: string;
  /** Por defeito ORIGIN. `null` omite o cabeçalho Origin. */
  origin?: string | null;
  headers?: Record<string, string>;
}

/** Chama o Worker como um browser: caminho relativo ou URL absoluta. */
export function api(path: string, init: ApiInit = {}): Promise<Response> {
  const headers = new Headers(init.headers);
  const origin = init.origin === undefined ? ORIGIN : init.origin;
  if (origin !== null) headers.set("Origin", origin);
  if (init.cookie) headers.set("Cookie", init.cookie);
  let body = init.body;
  if (init.json !== undefined) {
    headers.set("Content-Type", "application/json");
    body = JSON.stringify(init.json);
  }
  const url = path.startsWith("http") ? path : `${ORIGIN}${path}`;
  return exports.default.fetch(new Request(url, { method: init.method ?? "GET", headers, body }));
}

/** Extrai `sw_session=<token>` do Set-Cookie; null se não houver token (ex.: cookie apagado). */
export function sessionCookie(res: Response): string | null {
  const match = /sw_session=([^;]+)/.exec(res.headers.get("set-cookie") ?? "");
  return match ? `sw_session=${match[1]}` : null;
}
```

```ts
import type { MiddlewareHandler } from "hono";
import { ApiError } from "../errors";

const SAFE_METHODS = new Set(["GET", "HEAD", "OPTIONS"]);

/** Cabeçalhos de segurança em todas as respostas do Worker (os assets estáticos usam public/_headers). */
export const securityHeaders: MiddlewareHandler = async (c, next) => {
  await next();
  c.header("X-Content-Type-Options", "nosniff");
  c.header("X-Frame-Options", "SAMEORIGIN");
  c.header("Referrer-Policy", "same-origin");
};

/** Proteção CSRF: pedidos que alteram dados têm de trazer um Origin igual à origem do pedido. */
export const originCheck: MiddlewareHandler = async (c, next) => {
  if (!SAFE_METHODS.has(c.req.method)) {
    const origin = c.req.header("Origin");
    if (!origin || origin !== new URL(c.req.url).origin) {
      throw new ApiError(403, "forbidden_origin", "Origem do pedido inválida.");
    }
  }
  await next();
};
```

```ts
import type { AppEnv } from "../types";

export const SESSION_COOKIE = "sw_session";

const DAY_SECONDS = 86_400;

/** `Secure` só em HTTPS, para o desenvolvimento local em http://localhost funcionar em todos os browsers. */
function isHttps(c: Context<AppEnv>): boolean {
  return new URL(c.req.url).protocol === "https:";
}

export function setSessionCookie(c: Context<AppEnv>, token: string, ttlDays: number): void {
  setCookie(c, SESSION_COOKIE, token, {
    httpOnly: true,
    sameSite: "Lax",
    path: "/",
    secure: isHttps(c),
    maxAge: ttlDays * DAY_SECONDS,
  });
}

export function clearSessionCookie(c: Context<AppEnv>): void {
  deleteCookie(c, SESSION_COOKIE, { path: "/", secure: isHttps(c) });
```

```ts
import type { AuthUser } from "../types";
import { randomToken, sha256Hex } from "./crypto";
import { rowToAuthUser, type UserRow } from "./users";

const DAY_MS = 86_400_000;

/** Cria uma sessão. O token só existe aqui e no cookie; a D1 guarda apenas o hash. */
export async function createSession(
  db: D1Database,
  userId: string,
  ttlDays: number,
  now: number = Date.now(),
): Promise<{ token: string }> {
  const token = randomToken();
  const tokenHash = await sha256Hex(token);
  await db
    .prepare(
      "INSERT INTO sessions (token_hash, user_id, created_at, expires_at) VALUES (?1, ?2, ?3, ?4)",
    )
    .bind(tokenHash, userId, now, now + ttlDays * DAY_MS)
    .run();
  return { token };
}

/** Devolve o utilizador da sessão, ou null se o token não existir, tiver expirado ou a conta não estiver ativa. */
export async function findSession(
  db: D1Database,
  token: string,
  now: number = Date.now(),
): Promise<{ user: AuthUser; tokenHash: string } | null> {
  const tokenHash = await sha256Hex(token);
  const row = await db
    .prepare(
      `SELECT u.id, u.email, u.role, u.status, u.quota_bytes, u.used_bytes
       FROM sessions s JOIN users u ON u.id = s.user_id
       WHERE s.token_hash = ?1 AND s.expires_at > ?2 AND u.status = 'active'`,
    )
    .bind(tokenHash, now)
    .first<UserRow>();
  return row ? { user: rowToAuthUser(row), tokenHash } : null;
}
```

```ts
import { getCookie } from "hono/cookie";

/** Exige sessão válida e põe `user` e `sessionTokenHash` no contexto. */
export const requireAuth: MiddlewareHandler<AppEnv> = async (c, next) => {
  const token = getCookie(c, SESSION_COOKIE);
  const session = token ? await findSession(c.env.DB, token) : null;
  if (!session) {
    if (token) clearSessionCookie(c);
    throw new ApiError(401, "unauthorized", "Sessão inválida ou expirada.");
  }
  c.set("user", session.user);
  c.set("sessionTokenHash", session.tokenHash);
  await next();
```

```ts
const MAX_FAILURES = 5;
const WINDOW_MS = 15 * 60_000;

/** Verdadeiro com 5 ou mais falhas deste email nos últimos 15 minutos. */
export async function isLockedOut(
  db: D1Database,
  email: string,
  now: number = Date.now(),
): Promise<boolean> {
  const row = await db
    .prepare("SELECT COUNT(*) AS n FROM login_failures WHERE email = ?1 AND failed_at > ?2")
    .bind(email, now - WINDOW_MS)
    .first<{ n: number }>();
  return (row?.n ?? 0) >= MAX_FAILURES;
}

export async function recordFailure(
  db: D1Database,
  email: string,
  now: number = Date.now(),
): Promise<void> {
  await db
    .prepare("INSERT INTO login_failures (email, failed_at) VALUES (?1, ?2)")
    .bind(email, now)
    .run();
}

export async function clearFailures(db: D1Database, email: string): Promise<void> {
  await db.prepare("DELETE FROM login_failures WHERE email = ?1").bind(email).run();
}
```

```ts
const UNITS = ["B", "KB", "MB", "GB", "TB"];
const numberFormat = new Intl.NumberFormat("pt-PT", { maximumFractionDigits: 1 });

/** Tamanho legível em base 1024 (ex.: 1536 -> "1,5 KB"). */
export function formatBytes(bytes: number): string {
  if (!Number.isFinite(bytes) || bytes <= 0) return "0 B";
  let value = bytes;
  let unit = 0;
  // Compara o valor já arredondado para 1048575 B dar "1 MB" e não "1024 KB".
  while (unit < UNITS.length - 1 && Math.round(value * 10) / 10 >= 1024) {
    value /= 1024;
    unit++;
  }
  return unit === 0 ? `${Math.round(value)} B` : `${numberFormat.format(value)} ${UNITS[unit]}`;
}
```

```ts
export class ApiRequestError extends Error {
  readonly status: number;
  readonly code: string;

  constructor(status: number, code: string, message: string) {
    super(message);
    this.status = status;
    this.code = code;
  }
}

interface RequestOptions {
  method?: string;
  json?: unknown;
}

/** Chama a API. Devolve o JSON da resposta, `undefined` em 204, e lança `ApiRequestError` em erros. */
export async function apiFetch<T = void>(path: string, options: RequestOptions = {}): Promise<T> {
  const headers: Record<string, string> = {};
  let body: string | undefined;
  if (options.json !== undefined) {
    headers["Content-Type"] = "application/json";
    body = JSON.stringify(options.json);
  }
  const response = await fetch(path, {
    method: options.method ?? "GET",
    headers,
    body,
    credentials: "same-origin",
  });
  if (response.status === 204) return undefined as T;
  const data = await response.json().catch(() => null);
  if (!response.ok) {
    throw new ApiRequestError(
      response.status,
      data?.error ?? "unknown_error",
      data?.message ?? "Ocorreu um erro. Tente novamente.",
    );
  }
  return data as T;
}
```

```tsx
import { useState, type FormEvent } from "react";
import { useChangePassword, useMe } from "../auth";
import { Button } from "../components/Button";
import { Message } from "../components/Message";
import { TextField } from "../components/TextField";

export default function AccountPage() {
  const me = useMe();
  const change = useChangePassword();
  const [currentPassword, setCurrentPassword] = useState("");
  const [newPassword, setNewPassword] = useState("");
  const [confirm, setConfirm] = useState("");
  const [localError, setLocalError] = useState<string | null>(null);
  const [done, setDone] = useState(false);

  function onSubmit(event: FormEvent) {
    event.preventDefault();
    setDone(false);
    if (newPassword.length < 8 || newPassword.length > 128) {
      setLocalError("A senha nova deve ter entre 8 e 128 caracteres.");
      return;
    }
    if (newPassword !== confirm) {
      setLocalError("As senhas novas não coincidem.");
      return;
    }
    setLocalError(null);
    change.mutate(
      { currentPassword, newPassword },
      {
        onSuccess: () => {
          setCurrentPassword("");
          setNewPassword("");
          setConfirm("");
          setDone(true);
        },
      },
    );
  }

  const error = localError ?? change.error?.message ?? null;

  return (
    <div className="max-w-md">
      <h1 className="text-2xl font-bold tracking-tight">Conta</h1>
      <p className="mt-2 text-sm text-slate-600">{me.data?.email}</p>

      <h2 className="mt-8 text-lg font-semibold">Alterar senha</h2>
      <form onSubmit={onSubmit} className="mt-4 space-y-4">
        <TextField
          label="Senha atual"
          type="password"
          name="currentPassword"
          autoComplete="current-password"
          required
          value={currentPassword}
          onChange={(event) => setCurrentPassword(event.target.value)}
        />
        <TextField
          label="Senha nova"
          type="password"
          name="newPassword"
          autoComplete="new-password"
          required
          value={newPassword}
          onChange={(event) => setNewPassword(event.target.value)}
        />
        <TextField
          label="Confirmar senha nova"
          type="password"
          name="confirm"
          autoComplete="new-password"
          required
          value={confirm}
          onChange={(event) => setConfirm(event.target.value)}
        />
        {error && <Message kind="error">{error}</Message>}
        {done && <Message kind="success">Senha alterada com êxito. As outras sessões foram terminadas.</Message>}
        <Button type="submit" disabled={change.isPending}>
          {change.isPending ? "A guardar…" : "Alterar senha"}
        </Button>
      </form>
    </div>
  );
}
```
