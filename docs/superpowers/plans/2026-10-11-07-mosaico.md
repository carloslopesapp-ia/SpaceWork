# SpaceWork — Plano 7: mosaico em «Meu espaço» (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar a «Meu espaço» uma segunda vista, o **mosaico**: um seletor «Lista | Mosaico» (a escolha fica guardada no browser) e uma grelha de quadrados com a imagem das fotos pequenas e o ícone e a extensão nos outros ficheiros. É a fase 1: as miniaturas são a própria imagem, só das pequenas; as miniaturas geradas (fase 2) ficam para depois.

**Architecture:** Só interface: **nenhuma rota, nenhuma migração, nenhuma mudança no Worker**. `view-mode.ts` (o hook `useViewMode`, que guarda a vista em `localStorage` com `try/catch`), `ViewToggle` (o seletor), `thumbnails.ts` (a política: uma imagem de um tipo que se pré-visualiza e até 2 MiB mostra a imagem; o resto, o ícone e a extensão) e `Tiles.tsx` (`FolderTile` e `FileTile`), ligados em `FolderPage`. As imagens vêm de `/api/files/:id/preview`, que já existe, é da própria origem (a CSP das páginas permite `img-src 'self'`) e responde com `no-store`: por isso cada imagem do mosaico é uma descarga inteira a cada visita a uma pasta, e daí o limite de 2 MiB e o carregamento só quando o quadrado está perto do ecrã (`loading="lazy"`).

**Tech Stack:** o dos planos anteriores; nenhuma dependência nova.

**Spec:** [docs/superpowers/specs/2026-10-03-spacework-design.md](../specs/2026-10-03-spacework-design.md) (secção 8, interface). Índice dos planos: [README.md](README.md).

## Global Constraints

Valores da especificação e dos planos anteriores; todas as tarefas os cumprem implicitamente.

- Interface em português europeu.
- **Nada muda no Worker, na API nem na base de dados.** O mosaico usa só rotas que já existem.
- Uma imagem só é miniatura se o tipo se pré-visualiza (png, jpg, jpeg, gif, webp: **não** SVG nem PDF) e `size <= THUMBNAIL_MAX_BYTES` (2 MiB, o limite incluído); as outras mostram o ícone e a extensão (em maiúsculas, até 5 caracteres). A imagem carrega com `loading="lazy"`, é decorativa (`alt=""`, o nome já está por baixo), **não se arrasta** (`draggable={false}`: arrastá-la para a página enviava uma cópia, porque o Chromium põe a imagem no que se arrasta) e, se falhar, o quadrado passa ao ícone.
- A vista guardada é `"list"` ou `"tiles"` em `localStorage` (chave `spacework:view-mode`); a lista é a vista por defeito, e um valor desconhecido ou um armazenamento que falha (modo privado) valem a lista. A escolha vale para a página mesmo que não se consiga guardar. A vista é **por browser**, não por conta.
- Acessibilidade: o seletor é um grupo (`role="group"`, «Modo de apresentação») de dois botões com `aria-pressed`; o quadrado de um ficheiro que se pré-visualiza é um botão com o nome «Pré-visualizar <nome>»; o quadrado de uma pasta é uma ligação «Abrir a pasta <nome>»; o menu «⋮» é o mesmo da lista. O quadrado **não** leva `overflow-hidden` (cortava o menu): o corte é só no rosto.
- Os testes da interface (`npx vitest run -c vitest.web.config.ts`) e os de ponta a ponta (`npm run test:e2e`) mostram só o resumo: qualquer outra saída (avisos de `act`, `console.error`) é um defeito do teste a corrigir. Nenhum teste espera por temporizadores falsos.
- Este plano não instala nada, não toca na conta da Cloudflare, no GitHub nem em credenciais, e **não faz push**.
- Vitest `^4.1`.
- **Nenhum `git push` sem confirmação explícita do utilizador.**

- [ ] **Step 2: A implementação**

**`view-mode.ts`:** o armazenamento do browser pode lançar (modo privado, dados bloqueados, cheio), por isso a leitura e a escrita levam `try/catch`: ler cai na lista e escrever falha em silêncio, e o estado do React guarda a escolha na mesma. A chave é por browser, não por conta (não precisa de nenhuma rota nem coluna). **`ViewToggle`:** dois botões no mesmo grupo, com `aria-pressed`.

Criar `src/web/components/ViewToggle.tsx`:

```tsx
import type { ViewMode } from "../view-mode";

const OPTIONS: Array<{ value: ViewMode; label: string }> = [
  { value: "list", label: "Lista" },
  { value: "tiles", label: "Mosaico" },
];

/** O seletor «Lista | Mosaico»: dois botões premíveis (`aria-pressed`), no mesmo grupo. */
export function ViewToggle({ value, onChange }: { value: ViewMode; onChange: (mode: ViewMode) => void }) {
  return (
    <div role="group" aria-label="Modo de apresentação" className="inline-flex rounded-lg border border-slate-300 bg-white p-0.5">
      {OPTIONS.map((option) => (
        <button
          key={option.value}
          type="button"
          aria-pressed={value === option.value}
          onClick={() => onChange(option.value)}
          className={`rounded-md px-3 py-1.5 text-sm font-semibold focus:outline-none focus-visible:ring-2 focus-visible:ring-indigo-300 ${
            value === option.value ? "bg-indigo-600 text-white" : "text-slate-700 hover:bg-slate-50"
          }`}
        >
          {option.label}
        </button>
      ))}
    </div>
  );
}
```

Criar `src/web/view-mode.ts`:

```ts
import { useState } from "react";

export type ViewMode = "list" | "tiles";

export const VIEW_MODE_KEY = "spacework:view-mode";

/** A vista guardada neste browser (a lista, por defeito). O armazenamento pode falhar (modo privado, dados bloqueados): então, a lista. */
export function readViewMode(): ViewMode {
  try {
    return localStorage.getItem(VIEW_MODE_KEY) === "tiles" ? "tiles" : "list";
  } catch {
    return "list";
  }
}

/** A vista de «Meu espaço» (lista ou mosaico). A escolha fica guardada neste browser e vale para a página mesmo que não se consiga guardar. */
export function useViewMode(): [ViewMode, (mode: ViewMode) => void] {
  const [mode, setMode] = useState<ViewMode>(readViewMode);

  function choose(next: ViewMode) {
    setMode(next);
    try {
      localStorage.setItem(VIEW_MODE_KEY, next);
    } catch {
      // sem armazenamento: a escolha vale só para esta página
    }
  }

  return [mode, choose];
}
```

```ts
import { previewContentType } from "../shared/preview";
import type { FileItem } from "../shared/types";

/**
 * Até este tamanho, a imagem de um ficheiro serve de miniatura no mosaico. A API responde com `no-store`, por isso cada miniatura é uma
 * descarga completa e nova a cada visita a uma pasta: as imagens maiores mostram o ícone.
 */
export const THUMBNAIL_MAX_BYTES = 2 * 1024 * 1024;

/** Se o quadrado do ficheiro mostra a própria imagem: um tipo de imagem que se pré-visualiza (não um PDF nem um SVG) e dentro do limite. */
export function showsThumbnail(file: FileItem): boolean {
  return previewContentType(file.name)?.startsWith("image/") === true && file.size <= THUMBNAIL_MAX_BYTES;
}

/** A extensão do nome, em maiúsculas e até 5 caracteres («relatório.pdf» → «PDF»), para o quadrado de um ficheiro sem miniatura; vazia se não houver. */
export function extensionLabel(name: string): string {
  const dot = name.lastIndexOf(".");
  if (dot <= 0 || dot === name.length - 1) return "";
  return name.slice(dot + 1).toUpperCase().slice(0, 5);
}
```
